# راصد ومنظم صور الطلاب الذكي | Student Photo Matcher & Organizer

تطبيق Android احترافي متكامل مبني بنقاء وفق أحدث معايير تطوير تطبيقات Android الحديثة (Kotlin Native + Jetpack Compose Material 3 + Room DB + Pluggable OCR).

صُمم التطبيق خصيصاً للمدارس، والمعاهد، والجامعات، ولجان الامتحانات، والمصورين المحترفين لحل مشكلة مطابقة آلاف الصور الشخصية للطلاب مع شيتات وبيانات ملفات **Microsoft Excel (.xlsx)**، واستخراج كود التلميذ والرقم القومي والاسم بالذكاء الاصطناعي، ومراجعتها بصرياً، ثم إنتاج وتصدير صور جديدة بأسماء منظمة مع تحديث نسخة جديدة من ملف الإكسيل تلقائياً دون أي مساس بالملفات الأصلية.

---

## 🌟 الميزات الجوهرية والمعمارية الهندسية

### 1. استيراد ملف Excel متوافق مع معايير وزارة التربية والتعليم
- **ورقة العمل المستهدفة:** `بيانات الطلاب` (مع دعم اختيار أي ورقة أخرى).
- **صف العناوين:** الصف الرابع (Index 3).
- **بداية بيانات الطلاب:** الصف الخامس (Index 4).
- **الأعمدة المدعومة والمكتشفة تلقائياً:**
  - `A`: م / المسلسل
  - `B`: كود التلميذ
  - `C`: الرقم القومي (يُحفظ بدقة كسلسلة نصية `String` لمنع فقدان الأصفار البادئة إطلاقاً).
  - `D`: اسم التلميذ
  - `K`: اسم ملف الصورة الناتج (يُملأ تلقائياً عند التصدير).
  - `L`: ملاحظات وحالة المطابقة (يُملأ تلقائياً).
- **محرك OpenXML Streaming مخصص (`FastXlsxReader` & `FastXlsxUpdater`):** قراءة وتحديث ملفات XLSX فائقة الحجم دون استهلاك ذاكرة الرام ودون أي مكتبات ثقيلة، مع الحفاظ التام بنسبة 100% على كافة المعادلات والتنسيقات والصفوف والأعمدة الأصلية.

### 2. استيراد ومعالجة الصور دون قيود
- دعم كافة امتدادات الصور: `JPG`, `JPEG`, `PNG`, `WEBP`.
- التعامل مع آلاف الصور بكفاءة عالية عبر تجزئة العرض وتوليد الصور المصغرة (Downsampling & Paging).
- **أمان مطلق للأصول:** الحفاظ التام على الملفات الأصلية دون نقل أو حذف أو تعديل أو إعادة تسمية.

### 3. بنية OCR مرنة وقابلة للتبديل (Pluggable OCR)
- واجهة `IOcrEngine` تدعم تبديل المحركات بسلاسة.
- محرك **Google ML Kit** المحلي عالي الدقة، يعمل على الهاتف دون اتصال بالإنترنت حفاظاً على سرية البيانات.
- دعم محرك سحابي اختياري مُعطّل افتراضياً ولا يرسل أي بيانات إلا بموافقة صريحة يدوية وإدخال مفتاح API خاص بالمستخدم (Zero Hardcoded Keys).
- معالجة مسبقة ذكية للصور (`ImagePreprocessor`): رفع التباين بنسبة 35%، التحويل لتدرج رمادي عالي الجودة، واستقطاع مناطق النصوص.
- استخراج دقيق للرقم القومي (14 خانة يبدأ بـ 2 أو 3) وتجاهل الكلمات الدخيلة والتواريخ والشعارات.

### 4. محرك المطابقة الذكي متعدد المراحل
- **المرحلة 1:** فحص كود الطالب في اسم ملف الصورة كمرجع أولي.
- **المرحلة 2:** مقارنة الاسم العربي وتطبيعه (إزالة التشكيل، توحيد الهمزات `أ إ آ -> ا`، توحيد التاء المربوطة `ة -> ه`، واحتساب تشابه الكلمات والمسافات).
- **المرحلة 3:** مقارنة الرقم القومي كسلسلة نصية متكاملة.
- **المرحلة 4:** تقييم درجة الثقة (0-100%) وتصنيف النتائج وكشف التعارضات:
  - `مطابقة مؤكدة` (CONFIRMED_MATCH)
  - `مطابقة محتملة تحتاج مراجعة` (POTENTIAL_MATCH_REVIEW_NEEDED)
  - `تعارض في البيانات` (DATA_CONFLICT) - *ممنوع الاعتماد التلقائي مطلقاً في حالة التعارض*
  - `صورة بلا سجل مطابق` (NO_MATCHING_RECORD)
  - `سجل بلا صورة` (RECORD_WITHOUT_PHOTO)
- **ممنوع استخدام التعرف على الوجه لتحديد هوية الطالب.**

### 5. واجهة المراجعة البصرية (فردية وجماعية)
- وضع المراجعة الفردية (عرض الصورة بحجم مكبر، مقارنة الاسم من Excel والاسم من OCR، الرقم القومي، كود الطالب، درجة الثقة، وسبب المطابقة).
- وضع المراجعة الجماعية (Grid) لفرز واعتماد مئات الصور بسرعة.
- أزرار تحكم كاملة: اعتماد، رفض، تعديل النص المكتشف يدوياً، فك الربط، والتنقل السلس.

### 6. خيارات تسمية الصور الـ 6 الرسمية
1. **اسم الطالب فقط** (`{name}`)
2. **الرقم القومي فقط** (`{national_id}`)
3. **كود الطالب فقط** (`{code}`)
4. **اسم الطالب + كود الطالب** (`{name}_{code}`)
5. **اسم الطالب + الرقم القومي** (`{name}_{national_id}`)
6. **الرقم القومي + كود الطالب** (`{national_id}_{code}`)
- تنظيف تلقائي للأسماء من الرموز الممنوعة في نظام ملفات Android (`\ / : * ? " < > |`).
- منع الكتابة فوق الملفات بحل التعارض عبر إضافة لاحقة رقمية آمنة (`_2`, `_3`).

### 7. التصدير وتحديث Excel الآمن
- اختيار مجلد إخراج مستقل عبر نظام **Storage Access Framework (SAF)**.
- نسخ الصور المعتمدة فقط دون المساس بالأصول الأصلية.
- إنشاء نسخة جديدة من ملف Excel مع تعبئة العمود **K** باسم الصورة والعمود **L** بحالة المطابقة والملاحظات.
- إنشاء تقرير شامل بصيغة **CSV** مزود بـ UTF-8 BOM لفتحه مباشرة باللغة العربية في Excel.

### 8. استمرارية العمل وقاعدة بيانات Room
- حفظ تلقائي للجلسة وحالة الطلاب والصور في قاعدة بيانات Room المحلية.
- استعادة جلسة العمل واستكمالها فور فتح التطبيق في حال التوقف أو إعادة تشغيل الهاتف.
